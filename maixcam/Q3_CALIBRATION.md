# 第三问 MaixCAM 标定与联调

## 接线

| MaixCAM | 天猛星 |
|---|---|
| A21 / UART4_TX | PA22 / UART2_RX |
| GND | GND |

两端均为 115200、8N1、3.3 V 电平。

沿用已经测试成功的 D36A 控制线：

| D36A 控制信号 | 天猛星 |
|---|---|
| STEP | PB10 |
| DIR | PB11 |
| EN1（高电平使能） | PB0 |
| 信号地 | GND |

步进编码器为避免与循迹和 TB6612 冲突，必须使用：

| 编码器 | 天猛星 |
|---|---|
| A | PA2 |
| B | PA26 |
| PWM | PA25 |
| Z | PA16 |

## MaixCAM 图像标定

打开 `maixvision_yolov5_uart4_q3.py`，修改：

```python
AXIS_LEFT = (80, 240)
AXIS_RIGHT = (560, 240)
AXIS_LENGTH_MM = 250.0
POSITION_SIGN = 1
BALL_CLASS_ID = 0
```

`AXIS_LEFT/RIGHT`必须改成实际画面中凹槽轴线两端的像素坐标。
画面中的红、黄、绿线依次表示 -5 cm、O 点、+5 cm。

分别把球放在刻度 -5 cm、O、+5 cm 处，确认画面 POS 接近
-50.0 mm、0.0 mm、+50.0 mm。如果正负相反，将
`POSITION_SIGN`改为 -1。

## 按键

- 按键 1：`mode 0 -> mode 1 -> mode 2 -> mode 0`
- 按键 2：启动或停止当前模式
- mode 1：第二问循迹
- mode 2：第三问滚球

## 第一次通电顺序

1. 暂时关闭 D36A 动力电源，只开 MaixCAM、天猛星和编码器。
2. 完成 -5/0/+5 cm 图像坐标标定。
3. 不放钢球，开启 D36A，手动把摆杆调到近似水平。进入 mode 2
   短时启动，确认 OLED 进入 `CAM!` 且电机不主动偏转。
4. 停止后把钢球放在 O 点，降低 D36A 电流并准备立即停机；再次短时启动，
   观察状态由 `CHK` 进入 `P5` 时摆杆倾斜方向是否能让球趋向 +5 cm。
5. 如果控制方向完全相反，修改 `ball_q3.c` 中
   `Q3_CONTROL_SIGN`。
6. 方向正确后放球，先让球从小偏差回到 O 点，再测试完整流程。

当前初版把按键 2 启动瞬间的电机位置当作摆杆水平零位；因此每次启动
mode 2 前都要先把摆杆调到近似水平。PWM 绝对角度和 Z 信号会显示、计数，
但本版暂未用它们自动寻找机械水平零位。

## OLED mode 2

- `Q3`：`CHK/P5/N5/HOLD/DONE/CAM!/TIME/LIM!`
- `V`：视觉坐标是否有效
- `X`：钢球位置，单位 0.1 mm
- `T`：目标位置，单位 0.1 mm
- `E`：球位置误差，单位 0.1 mm
- `M`：电机相对零点的 A/B 编码器计数
- `P`：PWM 绝对角度
- `S`：任务秒数
- `C`：视觉置信度

当前控制增益只是安全联调初值，不能直接视为比赛最终参数。
